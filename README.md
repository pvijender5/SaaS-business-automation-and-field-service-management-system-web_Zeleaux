#  Zeleaux – Web Application

## 📘 Application Overview

The Zeleaux Web Application is built to support organizations in managing employee schedules, availability, and time tracking. Administrators can monitor real-time check-ins and check-outs, review employee availability, and manage data securely through an intuitive web-based interface.

## ⚙️ Tech Stack

### Backend

* **Framework**: CakePHP 3.x (MVC Framework)
* **Language**: PHP
* **Database**: MySQL
* **Authentication**: Custom Session-based Authentication
* **API Integration**: RESTful APIs for Mobile App Sync
* **Validation**: Server-side validation via CakePHP Validators

### Frontend

* **Template Engine**: CakePHP Views (PHP + HTML)
* **UI Framework**: Bootstrap
* **JavaScript**: jQuery
* **Form Handling**: Bootstrap-based form validation

### Other Tools & Features

* **File Uploads**: Integrated for employee documents and reports
* **Role-Based Access Control**: Admin and Staff-level permissions
* **Location Tracking (Optional)**: Integrated via Google Maps API when needed
